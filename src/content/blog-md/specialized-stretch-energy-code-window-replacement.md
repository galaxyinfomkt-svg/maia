More Massachusetts towns have voted to adopt the Specialized energy code, and the headlines usually mention net zero homes and all-electric buildings. If you only want to replace a few drafty windows or an old entry door, it is fair to wonder whether that vote changes your project.

For most replacement jobs, the Specialized code itself is not the part that applies. The rules for existing homes still matter, though, and the window you choose has to meet them. Here is how the pieces fit.

## Three energy codes, chosen town by town

The state's building energy code page describes three tiers, all based on the 2021 International Energy Conservation Code (IECC):

- **Base code:** IECC 2021 with Massachusetts amendments, in 780 CMR Chapter 11R for homes.
- **Stretch code:** IECC 2021 with key Massachusetts amendments, in 225 CMR 22 for homes.
- **Specialized code:** the Stretch code plus Appendix RC for homes, adopted by a town as an opt-in.

Each city and town chooses which tier applies. The state publishes a list of municipal adoption dates. Examples from the November 2026 list:

- **Charlton:** Stretch code since January 1, 2017, no Specialized code
- **Worcester:** Specialized code effective July 1, 2024
- **Hopkinton:** Specialized code effective January 1, 2025
- **Natick:** Specialized code effective July 1, 2025
- **Framingham:** Specialized code effective July 1, 2026

That list showed 60 municipalities with the Specialized code.

## What the Specialized code covers

The state's FAQ on the Stretch and Specialized codes answers the main question directly. It says the Stretch code applies to new construction as well as certain renovations and additions, while the **Specialized code applies only to new residential and commercial construction.** It also says extensive renovations and additions follow the regular Stretch code requirements.

The 2024 final draft of 225 CMR 22 states that **existing residential buildings shall comply with Chapter 5 of the Stretch energy code.** The FAQ adds that solar-ready provisions apply only to new construction, because the alterations section does not reference that appendix, and that EV readiness is also required only for new construction.

So in a Specialized code town, a window or door replacement on an existing house follows the existing building rules of the Stretch code, not the new construction pathways.

> For a window swap in an existing home, the questions that matter are the existing building rules and the window's ratings, whichever tier your town adopted.

### If the project is bigger than a window swap

If new windows are part of an addition or a gut renovation, the scope changes. The state FAQ says extensive renovations and additions follow the regular Stretch code requirements, even in a Specialized code town. Ask the building department which energy requirements apply to the full scope, and bring the whole plan in early, before products are ordered.

### Finding your town's tier

The state's adoption page links to a downloadable list of every municipality, with the dates each one adopted the Stretch and Specialized codes. The list we cite here is dated November 3, 2026. Towns keep voting on these codes, so check the current version for your town.

## What existing building rules usually ask of windows

The IECC has included a rule for replacement windows for several editions. A U.S. Department of Energy compliance brief, written for the 2009 through 2015 editions, explains that replacement units must meet the applicable U-factor and solar heat gain coefficient (SHGC) requirements, and cites the alterations section of the code for the 2015 edition.

Massachusetts now builds on the 2021 edition, and the exact maximum U-factor that applies to your job depends on the code edition and the amendments in force in your town. Massachusetts has revised the Stretch code text more than once in recent years, so we do not quote a single number here. Ask your building department which value applies, and compare it with the window's label.

### How to read the window label

The National Fenestration Rating Council (NFRC) label lets you compare windows, doors and skylights. NFRC explains that U-factor measures how well a product keeps heat from escaping, and the lower the number, the better it keeps heat in. SHGC measures solar heat: low numbers resist it, high numbers let it in. ENERGY STAR tells shoppers to look up a window's CPD number in the NFRC database to confirm its ratings.

## Doors

Exterior doors are part of the building envelope too, and NFRC's label program covers doors as well as windows. Ask your building department whether the energy code sets values that apply to a door replacement in your town, and keep the product's rating information with your permit paperwork.

## Permits still apply

At least one Massachusetts town building department describes window replacement as an energy conservation matter under the state building code, and many towns require a permit for it. See our guide to [permits for siding and windows](/blog/building-permit-siding-windows-massachusetts). The contractor should know which energy values the inspector will look for before the order goes in.

## Questions to ask before ordering

1. Which energy code tier has my town adopted, and since when?
2. Which maximum U-factor and SHGC apply to replacement windows under that code?
3. Does the window I am considering meet them? Can I see the NFRC label or directory listing?
4. Do the same rules apply to the door I want?
5. Will the permit application list the product ratings?
